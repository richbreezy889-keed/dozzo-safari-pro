# Dozzo Safari Brand

Design and refine a premium, modern safari website for:

DOZZO SAFARI

Dozzo Safari is a Tanzania-based safari and tour company.

BRAND COLORS:

The official organization colors are RED and BLACK.

Primary red:
#B5121B

Near black:
#0B0B0B

Secondary dark:
#151515

Warm light background:
#F7F5F2

White:
#FFFFFF

Muted text:
#6B6B6B

IMPORTANT DESIGN RULE:

Do NOT create a website where every section is bright red and black.

The red and black colors should establish the Dozzo Safari identity while authentic Tanzania safari photography provides the visual character.

The overall visual feeling should be:

PREMIUM
ADVENTUROUS
AUTHENTIC
MODERN
CONFIDENT
TANZANIAN
PROFESSIONAL

Think of a premium African safari company rather than a generic travel agency.

VISUAL DIRECTION

Use large, high-quality Tanzania wildlife photography.

Photography should dominate the visual experience.

Use:

full-width hero photography

large destination images

immersive package cards

clean white/light sections

sophisticated black sections

red accent elements

strong typography

generous spacing

subtle animations

Avoid:

cartoon safari graphics

excessive icons

excessive red

cheap tourism-template styling

excessive gradients

overly rounded UI everywhere

excessive animations

clutter

generic African patterns everywhere

HERO

Create a cinematic hero section.

Use an authentic Tanzania safari photograph.

Dark overlay for readability.

Headline:

"Experience Tanzania.
Discover the Wild."

Supporting text:

"Explore Tanzania's legendary national parks with Dozzo Safari — from unforgettable day trips to carefully planned multi-day adventures."

Primary CTA:

"Explore Safaris"

Secondary CTA:

"WhatsApp Dozzo"

Primary CTA should use Dozzo red.

Secondary CTA can use a dark/transparent treatment.

NAVBAR

Desktop:

Black or near-black navigation bar.

Dozzo Safari logo on the left.

Navigation in white.

Use red for:

active navigation state

booking CTA

subtle hover states

Navigation:

Home
Safaris
Destinations
About
Gallery
Contact

Prominent CTA:

"Plan Your Safari"

PACKAGE CARDS

Every safari package MUST have at least one high-quality image.

The image must accurately represent the destination.

Do not use one generic safari image for every package.

Each card should contain:

Image
Package name
Destination
Duration
Short description
Starting price when confirmed
View Safari
WhatsApp

Use red sparingly for the CTA and important information.

Cards should feel premium and clean.

DESTINATION SECTION

Create a visually strong Tanzania destination section.

Initial destinations:

Mikumi National Park
Nyerere National Park
Serengeti National Park
Ngorongoro
Tarangire

Use destination-specific photography.

Each destination card should have:

Large image
Destination name
Short factual description
Explore button

COLOR BALANCE

Recommended approximate visual balance:

60% light/white/sand backgrounds
25% black/dark sections
10% photography-driven visual areas
5% red accents

This is a guideline, not a rigid calculation.

Red should feel like a premium brand accent, not the entire website background.

DARK SECTIONS

Use black sections strategically.

For example:

"Why Travel With Dozzo?"

on a black background.

Use white typography.

Use red accent lines, numbers or buttons.

Example:

WHY DOZZO SAFARI?

01
Tanzania-focused experiences

02
Carefully planned itineraries

03
Flexible safari options

04
Personalised safari planning

Do not invent credentials or statistics.

TYPOGRAPHY

Use a premium modern sans-serif font for the primary UI.

Headings should be:

large
bold
confident
clean

Body text should be:

comfortable to read
not too small
well spaced

Avoid overly decorative fonts.

The typography should feel premium but accessible.

BUTTONS

Primary:

Dozzo Red background
White text

Secondary:

Black background
White text

Light-section secondary:

White/light background
Black text
Red border or subtle red accent

Buttons should have:

comfortable padding

strong contrast

clear hover state

touch-friendly mobile dimensions

MOBILE DESIGN

The website must be designed intentionally for mobile.

Do NOT simply shrink the desktop design.

At approximately:

360px
375px
390px
414px
430px

Ensure:

No horizontal scrolling
No overlapping text
No broken cards
No cropped buttons
No overflowing images
No tiny navigation
No unreadable sections

On mobile:

Use a hamburger menu.

Make WhatsApp/contact actions easily accessible.

Package cards should stack vertically.

Images should remain visually strong.

TABLET

Ensure the website works properly around:

768px
1024px

Cards should transition naturally between:

desktop grid

tablet grid

mobile stack

FOOTER

Use a strong black footer.

Include:

DOZZO SAFARI

Tanzania Safari Experiences

Navigation links

Safari links

Destinations

WhatsApp / Call:

+255 713 956 532

Instagram:

Dozzo_safari

Only use the actual verified Instagram URL when available.

Use red accents.

GALLERY

Create an immersive gallery.

Use approximately 12–20 high-quality Tanzania images initially.

Images should represent:

wildlife
landscapes
safari vehicles where licensed
parks
rivers
sunrise/sunset
traveler experiences where available

Use a responsive grid.

Include a lightbox.

Do not distort images.

IMAGES — CRITICAL

Every package must have an appropriate image.

Images must accurately correspond to the named Tanzania destination.

Mikumi package:

Mikumi-specific imagery.

Nyerere package:

Nyerere/Rufiji-specific imagery.

Serengeti package:

Serengeti-specific imagery.

Ngorongoro:

Ngorongoro-specific imagery.

Tarangire:

Tarangire-specific imagery.

Do not simply search for "African safari" and assign random images.

Do not use copyrighted images without appropriate permission/licensing.

When Dozzo supplies its own photographs, those should replace temporary stock imagery.

ANIMATION

Use subtle premium animations.

Examples:

fade-in
soft slide
image zoom on hover
button hover transitions
section reveal

Keep animations fast and elegant.

Do not over-animate.

Respect reduced-motion accessibility preferences.

OVERALL EXPERIENCE

The final website should immediately communicate:

"This is a professional Tanzania safari company."

A visitor should be able to:

Understand Dozzo Safari within seconds.

See beautiful Tanzania imagery.

Discover safari packages.

Understand where each safari goes.

Understand approximate duration.

View package details.

Contact Dozzo through WhatsApp.

Navigate easily on desktop, tablet and mobile.

The website should feel premium enough for an international traveler considering spending significant money on a Tanzania safari.

DO NOT make it look like a basic local business template.

Make it feel like a serious safari brand.
